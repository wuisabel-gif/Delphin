# Code of Conduct

Delphin is a small open source project, and the project should feel safe,
focused, and welcoming for contributors with different backgrounds and levels of
experience.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially when reviewing first-time contributions.
- Keep feedback specific to the work: code, tests, docs, behavior, and design.
- Make room for questions and clarification.
- Respect maintainers' time by keeping issues and pull requests focused.

## Unacceptable Behavior

- Harassment, threats, stalking, or sustained personal attacks.
- Insults, slurs, or demeaning language.
- Sexualized language or imagery.
- Publishing private information without permission.
- Repeatedly derailing issues, pull requests, or discussions after a maintainer
  asks you to stop.

## Scope

This code applies in project spaces including GitHub issues, pull requests,
discussions, documentation, and related community channels.

## Reporting

If you see behavior that violates this code, contact the project owner through
GitHub: [@wuisabel-gif](https://github.com/wuisabel-gif).

Reports should include links, screenshots, or other context when possible.
Maintainers will review reports privately, respond as promptly as practical, and
take action they believe is necessary to protect the project community.

## Enforcement

Maintainers may remove comments, close issues, block users, or restrict
participation when behavior harms the project or its contributors.

The goal is not ceremony. The goal is a project where people can do careful work
without being mistreated.
